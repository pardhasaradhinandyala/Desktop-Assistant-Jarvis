# Jarvis - Desktop Voice Assistant

## Project Description
Jarvis is a Python-based desktop voice assistant. It listens to voice commands and performs basic computer tasks.

## Features
- Voice recognition
- Text-to-speech
- Tells current time and date
- Opens Google
- Opens YouTube
- Searches Google
- Opens Notepad
- Opens Calculator

## Technologies Used
- Python 3.13
- SpeechRecognition
- PyAudio
- pyttsx3

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python jarvis.py
```
